# 元泽语录

元泽语录是[元泽](/people/students/26/元泽.md "元泽")的一系列 QQ 群发言，被截图后做成表情包，被大家用来代替发言

有记录以来第一句话应该是 2026/8/12 14:46 的“嘘。我有渠道”，并在当天被多次合并重组在聊天记录里，后被制成表情包

再接着[数滔](/people/students/26/数滔.md "数滔")和[双氧水咸鱼](/people/students/26/双氧水咸鱼.md "双氧水咸鱼")两位同学多次扩容补充语录，到现在发展非常庞大
