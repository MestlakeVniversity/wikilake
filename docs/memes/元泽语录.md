# 元泽语录

元泽语录是元泽的一系列QQ群发言，被截图后做成表情包，被大家用来代替发言

有记录以来第一句话应该是2026.8.12 14：46的“嘘。我有渠道”，并在当天被多次合并重组在聊天记录里，后被制成表情包

再接着数涛和双氧水咸鱼两位同学多次扩容补充语录，到现在发展非常庞大
