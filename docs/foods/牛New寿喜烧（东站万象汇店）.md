# 牛New寿喜烧（东站万象汇店）

地址就在东站东广场出来万象汇一层
寿喜锅自助，基础款130多r，这次奢侈一把，吃了个219r的套。感觉219的和牛和基础的牛上脑没什么区别，，然后我又不吃海鲜，烤榴莲还蛮好吃的，对喜欢吃榴莲的人是一大幸事 其他东西一如既往好吃。如果你对海鲜榴莲没有要求，我墙裂建议标准版，真的爽 饮品种类很多，哈根达斯自助冰淇淋依旧好吃，爽

补充:基础款有牛上脑，牛排肉部位的肉，还有五花，羊肉，黄喉。个人喜好锅底是寿喜锅+猪肚鸡
