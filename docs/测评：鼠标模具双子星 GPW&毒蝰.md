# 测评：鼠标模具双子星 GPW&毒蝰

Cbwzb发布：

这是一段送给FPS（第一人称射击游戏）新人玩家的鼠标选择指南。罗技GPW&雷蛇毒蝰是电竞鼠标模具界的双子星，都是重大手抓握鼠标，是聊鼠标永远都绕不开的话题。市面上的国产鼠标也大多仿照这两个传奇模具来设计模具。

GPW：让人感到匀称适中，抓握的时候背部能够很好的撑住手心，有一种掌握全局的感觉。

毒蝰：经过抓握优化，背部突起很高，手心前部有很大的顶手感，很有支撑，更多的是把你的手撑开进入高能状态的感觉。

这是两个鼠标的手接触区域示意图（本人手长21.5cm左右）

对于手小的同学或者是女生，这两个模具都有对应的等比例缩小版（罗技有GPW小狗，雷蛇有毒蝰mini（价格不菲），还有国产仿制供你选择）

我觉得很多时候看别人说其实很难做出一些判断，所以如果你想要测试一下你心仪的鼠标的话，你完全可以到H4-305来Have a try.
