# 本科生书院

本科生书院由4幢独立的建筑组成。它们目前采用数字编号（H1，H2，H3，H4）。



### H1



这啥不知道，没人住



### H2



这啥不知道，没人住



### H3



一栋空心方形红色宿舍楼。



经常作为临时活动场所，如体检和神秘小讲座。



寒暑假H4关闭时也曾作为留校学生的住宿区域。



目前（2025届之前）没有本科生正式入住，但是明年（按照扩招趋势）这里将会成为本科生的第二定居点。



### H4



一栋绿色（？）方形宿舍楼。



所有本科生的住宿与活动区域。



H4的一楼休息区被划分为4个书院（α，β，γ，δ）区域，但是随着招生规模的扩大，在可以预见的将来，4个书院将会各自占领一栋宿舍楼~~，到时候H4就全是我们δ的了啊哈哈哈哈哈~~。
