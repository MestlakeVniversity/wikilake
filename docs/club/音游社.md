# 音游社

## 这是什么

一个游走于校园内的神秘组织，成员以游玩"音乐游戏"为主要活动。

## 如何分辨音游社成员

音游社成员常年随身携带**平板**、**手机**或**电脑**等电子设备，以及**耳机**、**指套**或**手套**等辅助设备，进行打音游的活动。

#### 打音游

典型表现为使用**电子设备**进行意义不明的有节奏的大幅度**点击**、**滑动**等动作，少数表现为使用**机器或大屏**进行**拍打**、**挥舞**等动作，可能伴随着劲爆的噪音（如果他没有戴耳机的话）。

#### 平板/手机

最常见的一类成员，随处都有可能见到。

你可能随时随地看见有人拿出平板或手机，并对其做出暴力敲击行为，可能伴随着播放劲爆的噪音（如果他没有带耳机的话），请不要惊慌，这是音游社成员。

#### 电脑

不常见的一类成员，通常刷新于本科生书院beta公共空间的大桌以及一旁的小桌。

这类成员的特征是：1.以双手敲击键盘为主要操作方式，但不知为何他们只敲击其中四个键，且行为相比于上一类成员更为暴力；2.通常不会播放劲爆噪音，但他们敲击键盘的噪音远大于此。

其中有一类特殊成员，左手敲击键盘的两个特定按键，右手操作数位板，这也是音游社成员。

#### 耳机

戴耳机的人很多，戴有线耳机的却不多，但是音游社成员似乎偏爱这种不是很方便的设备。

另外，你应该庆幸身旁的音游社成员戴着耳机。

#### 指套

一般情况下，你仅会在使用平板/手机的音游社成员手指上看见指套。

据悉，这是为了方便他们的操作。

#### 手套

一般情况下，你仅会在一类被称为"舞萌吃"的音游社成员手上看见手套。

这同样是为了方便他们的操作，但是这需要搭配一类被称为"舞萌"的大型机台使用，校内并无此类设备。

如果你发现有人戴着手套进行意义不明的拍打、挥舞动作，请不要惊慌，这就是"舞萌吃"。产生这种现象的原因详见下文。
