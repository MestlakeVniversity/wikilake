# 测评：末匠A1钢笔：速写加硬钢尖版Capless

Capless送老妈了，没钢笔用，看到了国产capless风评好像还不错，100r，决定买来玩玩

东西一拆，内部跟capless只能说是完全一样，1：1复刻属于是

![末匠A1-拆解](/img/miscs/末匠A1-拆解.jpg "末匠A1-拆解")

我还买错了，买成EF（日系笔我一般都买F），写起来感觉不错，有点硬挺，还算丝滑，跟capless的18k笔尖没有半毛钱关系，根本没有那种Q弹，但是capless太软，刷题和考试明显没有这个国产版舒服，这个用来写作业肯定比Capless好。
