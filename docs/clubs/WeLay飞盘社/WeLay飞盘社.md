# WeLay飞盘社

西湖大学飞盘社，是一个充满活力与激情的学生社团，旨在推广飞盘运动，丰富学生课余生活，增强大家的团队合作精神和身体素质。我们的宗旨是通过飞盘运动促进同学们之间的交
流与合作，培养健康的生活方式，提升体育技能，并为大家提供一个放松身心、结交朋友的平台。我们每周定期在校园内举行飞盘训练，包括基本技术练习、战术讲解和实战演练。训练针对不同水平的会员，确保每个人都能找到适合自己的训练方式。 

定期组织与其他高校飞盘社和飞盘俱乐部的友谊赛，既增进了校际交流，也提高了社员的比赛经验和水平。邀请飞盘运动的专业教练和资深玩家来校分享经验和技巧，帮助社员更深入了解这项运动。不定期举办社团内部的联谊活动，增强成员间的凝聚力和友谊，营造温馨愉快的社团氛围。 

无论你是飞盘运动的初学者，还是已有丰富经验的老手，我们都热烈欢迎你的加入。西湖大学飞盘社期待与你一同在飞盘场上挥洒汗水，共享快乐！
