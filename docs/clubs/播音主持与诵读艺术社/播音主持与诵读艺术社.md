# 播音主持与诵读艺术社

西湖大学播音主持与诵读艺术社团是在校团委业务指导下，由学生自主发起的非营利性学生组织。社团以“以语言承载思想，以声音传递情感”为原则，致力于提升学生的语言表达能力、人文素养与艺术修养。 

社团主要面向全校师生开展活动，包括： 

1. 普通话基础与语言表达训练 —— 提升普通话标准化水平，训练气息、共鸣、停连、重音等基本功。 

2. 有声语言艺术实践 —— 通过主持、朗诵、演讲等形式，培养成员的舞台表现力与艺术感染力。 

3. 系统课程与团队训练 —— 提供系统化课程与例行训练，帮助成员形成由理论到实践的完整学习路径。 

4. 校园文化与美育建设 —— 组织晚会主持、朗诵节目、讲演活动等校园品牌项目，建设“西湖大学校园文化路线”，丰富校园文化生活，营造积极向上的人文氛围。 

5. 校际合作与交流 —— 通过交流活动拓展视野，促进文化与艺术经验分享。 

本社团旨在为学生提供一个专业、开放、包容的语言艺术平台，帮助成员提升沟通力、自信心与社会责任感，促进全面发展。同时，社团将积极弘扬中华优秀传统文化，倡导校园主流文化，推动学校美育建设与文化艺术水平的整体提升。
