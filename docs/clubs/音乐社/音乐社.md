# 音乐社

西湖大学音乐社是由西湖大学在籍学生基于对音乐的热爱自发组成的群众性团体。我们以“用音乐滋养科研生活”为核心理念，表达对生活的感知、感受与感悟，在旋律与节奏中寻找共鸣、释放情绪。音乐社的主要活动包括：参与或举办校内各类演出、以演出或兴趣为导向的日常排练、组织音乐沙龙与鉴赏会等。涵盖的音乐领域广泛，包括器乐（如管弦、民乐、钢琴、电声与乐队等）、声乐（如合唱、阿卡贝拉、小组唱与独唱等）以及音乐鉴赏（如古典音乐、音乐剧等）。无论你是擅长演奏演唱，还是单纯热爱聆听，音乐社都欢迎你的加入。我们相信，每一位热爱音乐的同学都能在这里收获快乐、释放活力！ 

社团负责人：谢穗榕（xiesuirong@westlake.edu.cn）
