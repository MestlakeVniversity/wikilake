# 篮球社

西湖大学篮球社成立于2025年，是一个充满活力与激情的社团。我们致力于为热爱篮球的同学们提供一个展示自我、提升球技的平台，同时通过组织各类篮球活动，增进同学们之间的交流与合作，丰富校园生活。社团定期开展训练活动，邀请专业教练进行指导，帮助成员们提高篮球技巧和战术水平。此外，我们还积极组织校内篮球比赛，与其他学校篮球社团进行交流赛，让成员们在实战中积累经验，感受篮球的魅力。无论你是篮球高手，还是初学者，只要你对篮球充满热情，西湖大学篮球社都欢迎你的加入，让我们一起在篮球场上挥洒汗水，追逐梦想. Go, go, Westlakers！
