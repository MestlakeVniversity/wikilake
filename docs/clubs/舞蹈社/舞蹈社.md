# 舞蹈社

想在中国舞的身韵流转中感受东方美感，或是在拉丁音乐的节拍里释放热情与活力吗？西湖大学舞蹈社欢迎每一个想要靠近舞蹈、感受舞台、结识伙伴的你。 

舞蹈社目前设有中国舞部和拉丁舞部两个方向。中国舞部开设古典舞、民族民间舞等课程，从基本功、身韵训练到剧目排练，带你感受中国舞的线条之美、气韵之美与表达之美；拉丁舞部开设伦巴、恰恰、牛仔、桑巴等课程，从基本步、节奏训练到舞蹈组合，带你体验拉丁舞的律动、配合与舞台感染力。 

这里既欢迎有舞蹈基础的同学继续提升，也欢迎零基础同学从第一节课开始尝试。无论是想放松身心、提升体态，还是想挑战舞台、认识朋友，都可以在这里找到属于自己的节奏。让我们在科研与学习之外，一起穿上舞鞋，在音乐中舒展身体，在练习中积累自信，在舞台上共同发光。
