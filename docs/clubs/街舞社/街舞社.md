# 街舞社

H.D. Crew 街舞社，为西湖大学所有街舞爱好者而生。我们致力于打造一个开放、包容的交流平台，让每个人都能在此尽享街舞的乐趣。 

我们真诚欢迎每一位成员的加入——无论你的舞蹈基础如何，无论你是本科生还是博士生，身处哪个学院。在这里，唯一的通行证就是你对街舞的热爱。 

在H.D. Crew，舞蹈不是为了竞技，而是为了表达。H.D. Crew是一个给你归属感的大家庭，更是一个激发你无限创造力的舞台。 

即刻加入H.D. Crew，让我们一起舞动，点燃热爱！
