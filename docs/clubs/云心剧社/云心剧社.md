# 云心剧社

走近话剧，了解话剧 

从生活出发，也回到生活 

你好，这里是西湖大学云心剧社。 

我们因为热爱话剧而相聚，也希望让更多人走近戏剧、了解戏剧，在创作与表演中发现生活，在舞台上表达自己。 

云心剧社希望为热爱话剧创作与表演的同学提供一个创作、实践、交流与成长的平台。 

在这里，我们将戏剧带进校园，通过观剧、话剧演出等活动，让更多人感受舞台、走近戏剧。 

在这里，我们通过专业课程与日常训练，从“模仿—反应—即兴”循序渐进地学习表演，在轻松的氛围中互相借鉴、共同提升。 

在这里，我们一起创作、一起排练，也一起经历一部作品从最初的想法走向舞台的过程，在戏剧中表达自己，也收获志同道合的伙伴与真挚的友谊。 

在这里，我们或许并不专业，却始终认真对待每一次创作。无论站在台前还是幕后，我们都希望通过自己的努力，将真正触动心灵的东西带到舞台上。 

无论你想成为创作者、幕后工作者，还是单纯想做一个热爱戏剧的观众，你都一定能在云心剧社找到你的一席之地： 

剧组：演员｜编剧｜导演｜语言指导｜形体指导 

制作支持：音乐｜灯光｜道具｜造型｜舞台监督 

活动部：剧社日常活动组织｜戏剧活动与社员交流 

后勤部：采购｜财务及其他日常事务 

宣传部：摄影摄像｜宣传内容｜视觉设计｜各剧组及活动的实况记录与宣传 

剧社家人：支持剧社作品｜参与剧社活动｜戏剧观看体验 

起源于热爱，也希望因热爱而延续。 

欢迎来到云心剧社。 

我们等你。
