# 博物社

西湖大学博物社创立于2023年，现为在杭高校绿色联盟成员社团。我们以“探索自然，博学万物”为宗旨，聚集了热爱自然的博物学者，引领西湖师生仰望浩瀚星空，探寻人文民风，观赏花鸟鱼虫，感受大自然的美妙。博物社自建社以来，先后多次组织了户外植物、昆虫、鸟类以及天文观星的科普认知活动以及室内标本制作，博物馆参观活动。此外，我们积极开展校外合作，先后与杭州日报，青山村等机构开展博物科普公益活动，回馈社会广大群体。在博物之旅中，让我们共同体验自然的奇妙与乐趣，领略大自然的美丽与神奇。
  
社团负责人：汤铭辉（tangminghui@westlake.edu.cn）
