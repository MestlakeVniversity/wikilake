# 动漫社

西湖大学NAL动漫社旨在为喜欢动漫和泛二次元（ACGN）的西湖大学同学提供同好交流和兴趣技能提升的平台。 

本社团定位为综合性ACGN社团，是一个充满包容力的大家庭。不管你是萌新还是大佬，不管你扎根于ACGN的哪片土地，都能在这里收获意想不到的快乐！我们的社团活动包括ACGN 欣赏与交流、互推安利等，根据社员兴趣和技能情况，将不定期开展ACGN相关技能的教学和交流活动，并面向全校进行成果产出和社团汇演。 

社团设有宅舞部、乐队部、WOTA艺与应援部、番剧部、创作部、游戏部、日语部、COS部、手作部等部门与多个支部及同好群。
