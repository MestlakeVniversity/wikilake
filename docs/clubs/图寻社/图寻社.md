# 图寻社

图寻社（GeoGuessr Club of Westlake）是由热爱地理探索与空间认知的学生自发组建的文化体育类学生社团。社团以图寻游戏和地理探索为载体，搭建集学习、交流、竞技于一体的实践平台。 

社团通过日常教学分享、组内定期竞赛、高校赛事备战等多元活动，帮助成员从基础操作入门，逐步掌握区域识别、线索分析、逻辑推理等核心能力，在趣味互动中拓宽全球视野、提升地理素养。

社团致力于营造开放包容的学习氛围，让图寻新手和进阶玩家都能在交流切磋中收获成长，并积极参与各类高校赛事，培养兼具观察力、判断力与协作力的探索型人才。
