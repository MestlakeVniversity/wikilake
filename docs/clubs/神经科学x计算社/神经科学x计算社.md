# 神经科学×计算社

一个念头如何诞生，一段记忆如何留下？我们能否用代码与模型，走近大脑与智能的奥秘？ 

神经科学计算社因这些好奇而生。我们希望汇聚西湖大学不同专业背景的师生，一起探索神经科学、计算科学与人工智能交汇处的未知。在这里，你可以带着尚未解答的问题，找到愿意一起思考、一起动手的伙伴。 

我们将通过专题讲座与分享，接触新的观点，让不同学科的思路相遇；通过系列教程与工作坊，从理解一个概念、运行一段代码开始，逐步深入感兴趣的问题。我们也将共同建设知识库，把学习中的发现、困惑与经验留下来，为后来者点亮探索的路。

无论你刚刚萌生兴趣，还是已经开始研究，都欢迎加入。带上你的好奇心，让我们一起探索大脑与智能的奥秘。
