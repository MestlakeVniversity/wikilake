# 创社记

　　彼时，有量子海洋。海洋中是泡沫，泡沫里是波浪，而波浪就是海洋。盘古既睡着，也醒着，而在泡影的一瞬，他的手脚再不互相牵绊，向无限远处探去。三千大千伴他的手脚而生，空间和时间被赋予意义，光也亦步亦趋。这是第〇天。

　　彼时，有分子气云。稠的浊，聚集成地；稀的清，升起为天；通天下一气耳。气就是风，风就是云，云就是气。永恒动的风在天地间跑过，天地间便长出想要静的物，看云卷云舒，有了生气。这是第九十二亿年。

　　彼时，有水球。地埋藏了火，而火向水肆意地奔去，于是水球中也有了风。四大在宏观互化，在微观互化，也在中观互化。风刮累了，在地上搭起区室，看火表演，让水休息。水的区室从大地落下，而大地也冲开了水。单区室的没有说要有地球，就有了地球。这是第九十九亿年。

　　彼时，有饥荒。有自养的从异养的中走出，说：“这是我的身体，不是为我生的，也不是为你们舍的，不必记念我；这是我的血，不是为我生的，也不是为你们舍的，不必记念我。”这是第一百亿年。

　　彼时，有多区室生物，有登陆，有万物。万物存在，正因为另有万物已不存在。不存在的万物用死亡使生命存在空白，于是存在的万物在万年的瞬间不复存在，而新万物便从无论生死的旧万物中出现。也正因此，不存在的正在存在的之中，存在的也总是不复存在。这是第一百三十二、一百三十三、一百三十四、一百三十五、一百三十六、一百三十七亿年。

　　彼时，有人。这是第一百三十八亿年，是人的第〇天。

　　彼时，有按工具而成的玩具。这是人的第二十万年。

　　彼时，有只为了娱乐而成的游戏。这是人的第二十九万五千年。

　　彼时，有浙江西湖高等研究院。一所新型大学正在知识的海洋里拔地而起，就要坐落在看云枕水的地方。这是人的第三十万年，是西湖大学的第〇天。

　　彼时，有游戏爱好者于西湖大学。或爱比拼，或想交友，机缘巧合，也终于聚在一处。“西湖壮大了，但学生还少，教职工们可以先组织起一个协会”。于是，喜爱棋牌、电竞的师生也有了一个拉人活动的组织。这是西湖大学的第三年又半，是棋牌电竞协会的第〇天。

　　彼时，有活动组织者于西湖大学。在协会中，其以学生身份充满热情地付出，奔走于校内外活动。“学生多了，但是这学年来不及成立社团了，登记一个兴趣小组吧”。这是棋牌电竞协会的第二年又半，是棋牌电竞社（兴趣小组）的第〇天。

　　彼时，有活动组织者于西湖大学。“我看你对棋牌电竞的发展挺有想法的，我后面应该要忙毕业了，社团交给你怎么样？”很早，有了英雄联盟部、王者荣耀部、战略游戏部、米哈游部、中国象棋部。冥冥之中，第一任社长主要发展了电竞，而第二任社长主要发展了棋牌，于是社团早有电竞活动的基数，而新生出了象棋、桥牌的活动，使传统棋牌也有了热度。所有部门开始生长，所有活动组织者热情奉献，于是社团活动渐多，而活动也从不限于部门。“新学年到了，棋牌电竞社正式成立为社团了。”这是棋牌电竞社（兴趣小组）的第八个月，是棋牌电竞社的第〇天。

　　彼时，有众多各类游戏玩家新入西湖大学。于是，棋牌电竞社的部门渐多，又有了桥牌部、围棋部、集换式卡牌游戏部、第一人称射击游戏部、国际象棋部，而中国象棋部更名象棋部、集换式卡牌游戏部更名卡牌对战游戏部。所有部门趋向成熟，所有活动组织者热情奉献，于是社团活动渐多，而活动也从不限于部门。这是棋牌电竞社的第〇天，第一天，到第三百六十五天；是棋牌电竞社一百二十余位发起人的第〇天，第一天，到第三百六十五天。

　　彼时，有众多各类游戏玩家新入西湖大学。所有部门趋向成熟，所有活动组织者热情奉献，于是社团活动渐多，而活动也从不限于部门。这是棋牌电竞社的第二年。

　　彼时，有众多各类游戏玩家新入西湖大学。社团部门再多，又有了第五人格部；而魔方社也并入社团，又有了魔方部。这是棋牌电竞社的第三年初。

　　彼时，或曰：“你怎么不从盘古开天讲起。”

　　彼时彼刻，恰如此时此刻。

　　彼时有的，后必再有。
