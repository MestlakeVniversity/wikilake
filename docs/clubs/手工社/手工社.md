# 手工社

手工社是由手作爱好者发起成立的学生社团。社团以“不赶时间，只造美好”为宗旨，希望在日常的课业压力之外，为每一位感兴趣的同学留出一小块可以慢下来的空间，让大家在动手创作的过程中，暂时放下焦虑，享受一段属于自己的安静时光。 

社团每学期组织开展主题手工活动，涵盖传统工艺与现代创意两大方向，包括编绳、螺钿胸针、宋锦发卡、漆扇、钩织、不织布植物等。活动以小班体验为主，由社团骨干亲自教学，手把手带大家从零开始完成一件属于自己的作品。零基础友好，工具材料一应俱全，无需自带任何物品。我们注重每一位参与者的沉浸式创作体验，不赶进度，不设标准，只希望每个人都能在手作中找回专注的平静与完成的喜悦。不赶时间，只造美好——是我们想传递的手作态度，也是我们想留在每个人心里的温暖余韵。
