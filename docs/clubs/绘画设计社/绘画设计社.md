# 绘画设计社

西湖大学绘画设计社旨在为爱好艺术的同学提供一个学习和展示自我以及互动交流的平台；

生活不止眼前的学业和科研，我们也能用画笔绘出心中的远方，在创作中享受着这片刻属于自己的美好。 

我们的一些活动： 

- 在中国传统节日期间举办具有西湖大学特色的大型绘画设计活动，如作品征集比赛与展览；巨幅绘画活动；特色手工作品制作等。 

- 定期举办绘画设计基础教学课程，为爱好艺术的同学提供学习条件。 

- 组织社员前往美院和各大艺术会展进行观摩交流，开拓眼界与提升情操。 

欢迎加入我们! 社团负责人：李志洲（lizhizhou@westlake.edu.cn）
