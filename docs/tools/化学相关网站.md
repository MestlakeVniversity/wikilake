# 化学相关网站

搬运：全篇原文来自“写给新生的西湖大学本科生新手教程.pdf”，无删改，不保证时效性

Pubchem（查数据神中神）[pubchem.ncbi.nlm.nih.gov](https://pubchem.ncbi.nlm.nih.gov/) 

CAS Scifinder（学校网站电子资源可以进去） 

X-MOL（有中英文双语站，查论文爽中爽）（我也觉得）只是把课题组招聘写得像小广告，其他没发现缺点 

Reaxys 真的很好用 数据查询也很方便 

一些数据难以查到可以使用一些卖化学试剂网站：Merck，Chemicalbook，化源网（查化学品安全性 MSDS 很好用）
